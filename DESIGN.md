# Design system ownership

The current CBF1488 Figma file is the source of truth for the mini-program. Its visual language is deep court blue, translucent navy panels, vivid blue primary actions and cyan highlights. The previous warm parchment/gold design was replaced. Surface-specific implementation notes live with the code they guide:

- [Mini Program design](./apps/mini-program/DESIGN.md)
- [Admin web design](./apps/admin-web/DESIGN.md)

The desktop admin has no desktop frame in the supplied Figma file; it follows the same visual tokens and interaction rules while using familiar desktop navigation and tables.

Do not reuse styles from the removed UniApp/first mini-program implementation as design reference.
